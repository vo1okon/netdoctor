# netdoctor

## Overview
`netdoctor` is the core Python package implementing an adaptive censorship-circumvention orchestrator for Windows 10/11 (x64). It combines layered network diagnostics (`probes.py`, `classifier.py`), DPI desync and preset compilation (`selector.py`, `presets.py`, `config_gen.py`), multi-protocol VPN subscription parsing and circuit-breaker health orchestration (`vpn.py`, `clash_api.py`, `orchestrators.py`), canary revalidation (`dynamics.py`), SQLite state persistence (`storage.py`), external binary downloading/verification and child-process supervision (`supervisor.py`), GitHub release self-updating (`updater.py`), and Typer CLI plus Tkinter desktop/Win32 tray UIs (`cli.py`, `gui_backend.py`, `gui.py`, `tray.py`).

## Invariants
- **Schema & Storage Safety**:
  - `[models.py:NetworkFingerprint.key]`: Format is strictly `f'AS{asn}:{kind.value}:{gateway_mac or "default"}'`.
  - `[storage.py:Storage._init_schema]`: Enforces SQLite `PRAGMA user_version == 2` (migrating v0→v1 tables/indexes and v1→v2 `decisions.pinned` column) with `timeout=15.0`, `busy_timeout=10000`, and `WAL` mode.
  - `[storage.py:Storage.cleanup_stale_decisions]` & `[storage.py:Storage.reset_unhealthy_state]`: Never delete pinned rows (`COALESCE(pinned, 0) = 0`); `[storage.py:Storage.has_usable_vpn]` always returns `False` when `settings['stack_mode'] == 'dpi_only'`.
  - `[storage.py:Storage.record_domain_test]`: Retains at most the 30 newest `domain_tests` rows per `(network_key, domain)`.
- **Security, Elevation & Conflict Guards**:
  - `[supervisor.py:_safe_rel_path]` & `[supervisor.py:_safe_extract_file]`: Rejects ZipSlip traversal (leading/trailing `/`, `:`, `.`, `..`, `\x00`) and verifies `target.is_relative_to(root_resolved)`; `[supervisor.py:verify_binaries]` validates 17 `required_manifest_entries`, exact byte sizes, SHA-256 hashes, `b'MZ'` PE headers (`_is_pe_binary`), and pinned `UPSTREAM_RELEASES` tags.
  - `[updater.py:apply_app_update]`: In `'git'` mode aborts on dirty tracked files and requires `--ff-only`; in `'portable'` mode accepts only `https://github.com/vo1okon/netdoctor/` or `https://api.github.com/repos/vo1okon/netdoctor/` URLs and allowlisted relative paths.
  - `[cli.py:cmd_apply]`, `[gui_backend.py:GuiBackend.start_services]`, `[gui_backend.py:GuiBackend.reload_winws2]`: Require `_is_admin()` to start/reload `winws2`/`sing-box` TUN, and refuse to start if `detect_bypass_active()` is true unless `force=True`.
- **Probe, Classifier & Routing Boundaries**:
  - `[probes.py:probe_tls]` & `[probes.py:probe_stall]`: Disable certificate/hostname verification (`CERT_NONE`, `check_hostname=False`) solely to isolate SNI DPI and post-handshake throttling (capped at 32,768 bytes); `[probes.py:probe_quic]` pads synthetic QUIC v1 Initial packets to ≥ 1200 bytes.
  - `[classifier.py:classify_probes]`: Short-circuits to `UNKNOWN` when both system and DoH DNS fail, and to `IP_BLOCK` on TCP `timeout`/`reset`/`refused`; classifies `SNI_DPI` only when `real_sni` resets/times out while `neutral_sni == 'ok'`.
  - `[config_gen.py:generate_singbox_config]` & `[gui_backend.py:GuiBackend.trigger_apply_configs]`: Unlocker Guard protected domains (`ANTIGRAVITY_CRITICAL_DOMAINS`, filtered hosts entries, custom exclusions) are forced to `dns-local` / `direct` and excluded from VPN/DPI rules; process/game bypass rules are scoped to `inbound=['tun-in']` when `enable_tun=True`; `tun_stack` is clamped to `{'gvisor', 'mixed', 'system'}` and `stack_mode` to `{'hybrid', 'dpi_only'}`.
  - `[presets.py:compile_zapret_preset]`: Rejects empty presets, missing `--lua-init=` scripts, or zero surviving `--lua-desync=` profiles, and drops profiles with unresolved positive `--hostlist=`/`--ipset=` references to prevent wildcard matching.
- **Process Supervision, Failover & Threading**:
  - `[supervisor.py:ProcessSupervisor.start_stack]`: Atomically rolls back all started services via `stop_all()` if any service fails to start or exits during `startup_wait`; `[supervisor.py:ProcessSupervisor.stop_process]` waits up to 2.5s for `SERVICE_PORTS` release and uses PID + `create_time()` matching (`<= 2.0s`) to prevent PID-reuse false positives.
  - `[orchestrators.py:VpnLayerOrchestrator.record_node_result]`: Circuit breaker opens after 2 consecutive failures (or `half_open` failure) with `QUARANTINE_BACKOFF_SEC = (60, 180, 600, 1800)`; `[orchestrators.py:VpnLayerOrchestrator.should_switch_active_node]` enforces a 120s cooldown and requires `cand_rtt < active_rtt * 0.65` and `> 120 ms` improvement.
  - `[orchestrators.py:RealtimeConnectionMonitor.auto_heal_connections]`: Never modifies `pinned` decisions or runs while `active_zapret_preset_id != 'auto'`.
  - `[gui_backend.py:GuiBackend]`: Serializes config/service mutations with `RLock` (`_lock`), binary downloads with `Lock` (`_deps_lock`), and prevents re-entrant VPN reconciliation via `_vpn_reconciling`; `[gui.py:NetdoctorGuiApp]` enforces main-thread marshaling via `_post` / `_drain_post_queue` and guards closed/exiting lifecycle state (`_closed`, `_exiting`).

## Side Effects
- **SQLite Database (`netdoctor.db`)**: `[storage.py:Storage]` creates/migrates schema, upserts networks/verdicts/decisions/strategies/subscriptions/custom DNS/presets/node health/settings/domain test history, and runs stale/unhealthy cleanups.
- **Filesystem Mutations**:
  - `[config_gen.py:generate_winws2_config]`, `[config_gen.py:generate_singbox_config]`, `[config_gen.py:generate_xray_bridge_config]`, `[presets.py:compile_zapret_preset]`, `[cli.py:build_winws2_launch_cmd]`: Create directories and write `configs/winws2_preset.txt`, `configs/winws2_live_at.txt`, `configs/sing-box.json`, `configs/xray.json` (or unlink `xray.json`), and `lists/*.txt` (`exclude_vpn_ips.txt`, `exclude_unlocker_domains.txt`, `ipset-telegram.txt`, per-strategy hostlists).
  - `[supervisor.py:fetch_all_bins]` & `[supervisor.py:ProcessSupervisor]`: Atomically write binaries/lists/presets and `bin/manifest.json`, and rotate/write `logs/<service>.log`, `logs/<service>.prev.log`, and `logs/supervisor_state.json`.
  - `[tray.py:write_app_icon]` & `[tray.py:create_gui_shortcut]`: Write `.ico` files and invoke PowerShell `WScript.Shell` COM to create/patch `.lnk` shortcuts.
  - `[updater.py:apply_app_update]`: Executes `git pull --ff-only` or extracts release ZIP files into the repository root and runs `pip install`.
- **Subprocesses & OS Integrations**:
  - `[supervisor.py:ProcessSupervisor]`, `[cli.py:cmd_apply]`, `[gui_backend.py:GuiBackend]`: Spawn, monitor, and terminate `winws2.exe` (WinDivert driver), `sing-box.exe` (TUN interface), `xray.exe`, `tg-ws-proxy`, and `ciadpi.exe` process trees.
  - `[probes.py:_detect_default_gateway_mac]`, `[selector.py:run_blockcheck2_for_domain]`, `[gui_backend.py:GuiBackend.flush_windows_dns_cache]`: Invoke `route print 0.0.0.0`, `arp -a`, Cygwin/CMD `blockcheck2`, and `ipconfig /flushdns`.
  - `[tray.py:NetdoctorTrayIcon]`, `[tray.py:acquire_single_instance_mutex]`, `[tray.py:set_autostart_enabled]`, `[gui_backend.py:elevate_gui]`: Call Win32 kernel32/user32/shell32/gdi32 APIs (tray icon, mutex, `ShellExecuteW` UAC elevation), `schtasks` Task Scheduler CLI, and `dwmapi.DwmSetWindowAttribute` (`[gui.py:NetdoctorGuiApp._apply_window_chrome]`).
- **Network I/O**:
  - `[probes.py]`, `[dynamics.py]`, `[orchestrators.py]`, `[selector.py]`: Execute UDP/TCP/TLS/HTTP/DoH/QUIC probes, `https://speed.cloudflare.com/meta` ASN lookups, and background `socket.gethostbyaddr` rDNS threads.
  - `[vpn.py]`, `[supervisor.py]`, `[updater.py]`, `[clash_api.py]`: Perform HTTP(S) GET/PUT/DELETE requests to subscription URLs, GitHub Releases/release assets, and local Clash API (`127.0.0.1:19090`).
