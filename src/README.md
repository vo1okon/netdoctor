# src

## Overview
Source root for the `netdoctor` Python package, containing all runtime orchestration, network probing, DPI/VPN configuration generation, process supervision, CLI, desktop GUI, and Windows tray integration modules.

## Subdirectories & Boundaries
- [netdoctor](./netdoctor/README.md) - Adaptive censorship-circumvention orchestrator package (`models`, `probes`, `classifier`, `selector`, `presets`, `config_gen`, `vpn`, `clash_api`, `storage`, `supervisor`, `orchestrators`, `dynamics`, `updater`, `cli`, `gui_backend`, `gui`, `tray`).
